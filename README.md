# 🌸 گل‌های بهشت - لندینگ پیج معرفی محصول

یک لندینگ پیج زیبا و مدرن برای معرفی و فروش گل‌های طبیعی.

## ✨ ویژگی‌ها
- اسلایدر تصاویر با قابلیت اسکرول خودکار
- طراحی واکنش‌گرا (Responsive) مناسب برای موبایل و دسکتاپ
- گالری تصاویر با جلوه hover
- فرم تماس و اطلاعات ارتباطی کامل در فوتر

## 🛠 تکنولوژی‌ها
- HTML5
- Tailwind CSS
- JavaScript
- Swiper.js

## 🚀 اجرای پروژه
کافی است فایل `index.html` را در مرورگر خود باز کنید.
